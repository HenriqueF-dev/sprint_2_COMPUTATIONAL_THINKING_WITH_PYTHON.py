## 🎯 Sobre o Projeto

O StudyLens simula as funcionalidades de um aplicativo de câmera inteligente para estudantes. Nesta etapa, o sistema roda via terminal e permite cadastrar matérias, registrar anotações de aula e visualizar um resumo completo do que foi estudado.

---

## ⚙️ Funcionalidades

### 1. Cadastrar Matéria
Adiciona uma nova matéria ao sistema com validação de nome vazio e duplicidade.

### 2. Registrar Anotação de Aula
Registra o conteúdo de uma aula em uma matéria existente, informando data, conteúdo e se foi tirada foto da lousa.

### 3. Visualizar Resumo
Exibe todas as matérias com seus registros, total de aulas e quantas tiveram foto da lousa.

## ▶️ Como Executar

**Requisitos:** Python 3.x instalado

```bash
python studylens_projeto.py
```

No menu, escolha a opção desejada digitando o número correspondente e pressione Enter.
